# kuramoto

Exploring applications of Kuramoto oscillator networks, and the capabilities of unconventional computing technologies like Unconventional (the company).

## Layout

- `pymoto/` — core library for building and training Kuramoto oscillator network models
- `experiments/` — applied experiments (e.g. `cartpole`, `mnist`) built on top of `pymoto`
- `docs/` — background and design notes
